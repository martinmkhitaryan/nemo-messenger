# Nemo v1.2 (later)

This file is **later** than [`v1.1.md`](v1.1.md). It is **not** a specification: `README.md`, `docs/decisions/`, and `docs/protocol/` win if they disagree.

Every row needs a **new ADR** before anyone writes protocol objects, tables, or client code. Next free ADR is still **0036** (reserved for FCM in v1.1). Do not start these while v1.1 is open.

---

## Later product

| ID | Item | Why it waits | Blocks |
| --- | --- | --- | --- |
| L1 | Video calls | Group *voice* first ([v1.1](v1.1.md) N3). Extra SFU, bandwidth, and traffic shape. | New ADR after N3 |
| L2 | Key transparency | Public log and a new service; not a client checkbox. | New ADR |
| L3 | Group migration between homes | Hosted groups stay on the server that created them. Moving the group is a new protocol. | New ADR; README 53.12 |
| L4 | Group re-form after a long host outage | Clients reject External Commits and ReInit today ([ADR-0018](decisions/0018-group-join-and-member-credentials.md)). | New ADR; README 53.12 |
| L5 | Anonymous group membership | v1 host may see the member capability set ([ADR-0017](decisions/0017-server-hosted-group-streams.md)). Hiding that is a new group design. | New ADR |
| L6 | Global or privacy-preserving contact discovery | v1 is invite-first ([ADR-0006](decisions/0006-invite-first-discovery.md)). A directory is a new service. | New ADR |
| L7 | Mixnets / stronger global-observer anonymity | A different network, not a mode flag. Maximum already exists for optional slots ([ADR-0021](decisions/0021-privacy-layer-and-modes.md)). | New ADR |
| L8 | Cross-server TURN issuance | Federated 1:1 calls when each side's home issues TURN. | New ADR; README 53.12 |
| L9 | Desktop delivery while the app is not running | No desktop equivalent of FCM. v1.1 N4 is Android wake only. | New ADR; README 53.12 |
| L10 | Multi-use or long-lived group invite links | v1 invites are one-time, short TTL on purpose ([ADR-0018](decisions/0018-group-join-and-member-credentials.md)). | New ADR that supersedes 0018 |
